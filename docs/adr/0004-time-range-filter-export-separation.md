# ADR: 時間範囲フィルタの適用対象を表示とエクスポートで分離する

- Status: Accepted
- Date: 2026-03-27

## Context

画面では問題の発生時間帯に絞り込み、エクスポートには前後のログも含めたいという要件がある。
時間範囲フィルタを表示とエクスポートの両方に常時適用すると、この使い分けができない。

## Decision

時間範囲フィルタは画面表示に適用し、エクスポートへの適用はユーザーが選べるようにする。

## Decision Details

- エクスポート UI に「時間フィルタを無視する」トグルを提供する。
  - 有効時：入力データの全時間範囲を出力する。
  - 無効時：設定中の時間範囲フィルタを適用して出力する。
- 開始時刻と終了時刻の初期値は、読み込んだファイルの全時間範囲とする。
- UTC とローカルタイムの切り替えは、表示とフィルタ入力の両方に反映する。
- ノードや severity など時間範囲以外のフィルタは、エクスポート時にも常に適用する。

## Alternatives Considered

- 表示のフィルタ結果を常に出力する：全期間の出力時にフィルタを解除する手間がかかるため不採用。
- エクスポート専用の時間範囲入力：入力項目が増え、UI が複雑になるため不採用。

## Consequences

- 表示と出力で対象期間を柔軟に切り替えられる。
- トグルの意味を伝えるため、ツールチップで補足する。

## Verification / Guardrails

1. 時間範囲による表示の絞り込みを E2E テストで検証する。
2. トグルに応じて出力の時間範囲が切り替わり、他のフィルタは維持されることを検証する。
3. UTC とローカルタイムの切り替え時に、フィルタ入力値が正しく変換されることを検証する。
